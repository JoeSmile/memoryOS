# infra/docker

Docker 镜像与 Compose 编排配置。

## 规划内容（EP08）

- `apps/web/Dockerfile` — Next.js 多阶段构建（standalone）
- `apps/api/Dockerfile` — FastAPI slim 镜像
- `docker-compose.yml` — web、api、postgres、redis、nginx 一键启动
- `.env.production.example` — 生产环境变量模板
