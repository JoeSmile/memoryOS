## Turbopack（按版本，勿记混）

| 环境 | next@15.5.18 |
|:-----|:-------------|
| **dev** | `next dev --turbopack` ✅ 稳定 |
| **build 默认** | `next build` → **Webpack** |
| **build 可选** | `next build --turbopack` → **Beta** |
| **Next 16+** | dev + build **默认** Turbopack |

- Rust 实现，dev 下 HMR/冷启优于 Webpack（大项目更明显）
- CI：生产若仍用默认 `next build`，缓存的是 Webpack 产物；切 Turbopack build 需单独验证
