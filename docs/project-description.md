MemoryOS AI全栈项目 - 12周完整版学习+实战计划（可直接使用）

求职方向：AI应用全栈工程师 / LLM应用开发 / RAG平台开发
架构方案：FastAPI+Next.js + LangGraph流程编排 + LangSmith全链路调试 + LlamaIndex自研知识库 + 向量库+容器化部署

🛠 完整全量技术栈
一、前端技术栈

- 核心框架：Next.js 15 + React 18
- 编程语言：TypeScript
- 样式方案：Tailwind CSS
- 代码规范：ESLint + Prettier
- 路由体系：App Router
- 状态管理：Zustand
- 流式通信：SSE 客户端、ReadableStream
- 内容渲染：react-markdown、代码高亮、表格/引用渲染
- 进阶能力：文件分片上传、长列表优化、AI交互状态管理
  二、后端Python技术栈
- Web框架：FastAPI + uvicorn异步运行
- 异步体系：async/await 异步IO、异步依赖注入
- 数据校验：Pydantic V2
- 网络请求：httpx 异步请求库
- 接口规范：RESTful、SSE流式接口
- 权限体系：JWT登录鉴权
- 工程能力：全局异常捕获、中间件、统一日志
  三、数据库 & 缓存 & 向量存储
- 关系型数据库：PostgreSQL
- ORM框架：SQLAlchemy
- 数据库迁移：Alembic
- 向量拓展：pgvector
- 缓存中间件：Redis
- 文件存储：本地存储 / 腾讯云COS
  四、LLM框架核心栈

1. 流程编排：LangGraph

- 状态机设计、节点拆分、分支流转、循环执行、人机交互节点
- 适配Agent多轮思考、工具调用、流程中断与恢复

2. 全链路调试：LangSmith

- 流程链路追踪、耗时统计、Prompt可视化、入参出参日志
- 异常定位、流程卡死排查、生产环境问题复盘

3. 知识库双架构

- 快速落地：LangChain 生态快速RAG
- 深度自研：LlamaIndex 全套自建体系
  - 自定义文档加载器、自定义文本分割器
  - 自主Embedding管理、检索器重排、Query改写
  - 全局Token精准统计、上下文长度强制管控

4. 模型适配

- 统一封装层：兼容OpenAI/DeepSeek/通义千问/本地私有化LLaMA系列
- 多模型路由、模型自动降级、流量灰度切换
  五、AI核心业务技术
- 基础能力：Prompt工程、Few-shot、思维链、角色人设配置
- 流式体系：全链路SSE流式输出、实时Token推送、生成中断
- 函数调用：Function Calling 原生规范 + 框架标准化封装
- Agent体系：ReAct架构、规划-执行-观测闭环、工具注册与路由
- 记忆体系：短期滑动窗口记忆、长期用户画像记忆、对话摘要压缩
- RAG全链路：文档解析→预处理→切块→向量化→召回→重排→上下文组装→溯源引用
- 成本管控：全局Token统计、用户级用量配额、会话级上下文节流
  六、工程化 & 运维部署栈

✅ 核心架构&开发避坑准则（面试+实战核心）

1. 框架使用原则

- 业务流程、状态流转交给 LangGraph 管理，解耦易维护、可迭代、可调试
- 问题排查、流程观测全权依赖 LangSmith，线上线下统一调试标准
- 知识库深度定制、Token强管控、私有化定制需求，统一用 LlamaIndex 自研实现
- 简单快速业务复用LangChain，三套技术栈灵活混搭，不冲突、不冗余

2. Token成本管控核心落地点

- 切块阶段：LlamaIndex自定义分割器，强制限制单块字符/Token上限
- 拼接阶段：对话上下文自动裁剪，拒绝无限制拼接历史对话
- 统计层面：输入Token+输出Token双向统计，可拓展后台用量看板、用户配额限制

3. 私有化模型预留方案

- 项目预留本地大模型接入接口，可无缝对接LLaMA、Qwen等本地部署模型
- 区分商用API调试环境与本地模型推理环境，支持一键切换适配

4. 面试高分核心话术储备
