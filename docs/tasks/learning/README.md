## 如何使用

每条学习项建议维护两个维度（可在同一行用 emoji 自评）：

| 标记 | 含义 |
|:----:|:-----|
| 📖 | 已理解：能画图或向他人讲解 |
| 🔧 | 已落地：代码/配置在仓库中有对应路径 |

勾选 `- [ ]` 表示「至少完成 📖」；在 [weekly-tracker.md](../weekly-tracker.md) 中注明落地路径。
